# TORQO

**De kracht achter je showroom.** Verkoopsoftware voor autobedrijven: klanten,
voorraad, proefritten, offertes, koopovereenkomsten, afleveringen en facturen.

## Downloaden

De nieuwste installer staat altijd hier:
**[Releases → nieuwste versie](https://github.com/909MT4RJ/TORQO/releases/latest)**

Download `TORQO-Setup-<versie>.exe` en dubbelklik om te installeren. Zegt
Windows "Windows heeft uw pc beschermd"? Klik op **Meer info** en daarna op
**Toch uitvoeren**.

Na de installatie werkt TORQO zichzelf automatisch bij vanuit deze releases.
Je hebt een licentiecode nodig om TORQO te gebruiken.
